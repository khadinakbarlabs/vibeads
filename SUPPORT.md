# Support

Publisher: Khadin Akbar. For documentation and general support, use the [VibeAds repository](https://github.com/khadinakbarlabs/vibeads) and [GitHub Issues](https://github.com/khadinakbarlabs/vibeads/issues). For private security reports, use [GitHub private vulnerability reporting](https://github.com/khadinakbarlabs/vibeads/security/advisories/new).

For a troubleshooting report, include the plugin version, assistant surface, CLI version, Actor name, selected build, non-sensitive input fields, observed outcome and a short sanitized error message. Do not include tokens, passwords, customer-level records or private dataset URLs. Supply private run IDs only through a secure support channel when specifically needed.

If the CLI is unavailable, use planning mode. If authentication is missing, the user signs in through the official Apify CLI. For unsupported markets or empty/partial provider results, keep valid evidence, mark the affected coverage and review inputs before authorizing another paid attempt. A second run needs fresh approval if it changes scope or incurs additional charges.

For security reports, follow SECURITY.md. For Apify account or billing problems, use official [Apify Support](https://help.apify.com/); VibeAds cannot modify billing or credentials.
